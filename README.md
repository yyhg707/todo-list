# 待办清单 Todo List

《互联网软件开发技术与实践》第 1 课课后作业 — 用氛围编程完成的小项目。

## 功能

- 添加待办事项
- 点击勾选完成 / 取消完成
- 删除待办事项
- 全部 / 进行中 / 已完成 三种筛选
- 双击文本可直接编辑
- 一键清除所有已完成
- 数据通过浏览器 localStorage 本地持久化，不依赖后端

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 技术栈

- 原生 HTML + CSS + JavaScript
- localStorage 本地存储
- 单文件，零构建

## 课程说明

本项目为氛围编程（Vibe Coding）练习产物，凭简短自然语言描述生成，未先写规约。后续课程将在此基础上对比 SDD 规约驱动开发的差异。
